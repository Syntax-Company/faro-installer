  ⚠️ CADA CLUSTER DE WORKLOAD NECESITA ARGO CD Y ARGO ROLLOUTS.

     No este cluster: Faro no despliega donde vive. Escribe los manifiestos en el
     repositorio de GitOps y crea un Application de Argo CD EN EL CLUSTER DE
     DESTINO, hablando con él por el kubeconfig que custodia.

       kubectl create namespace {{ .Values.argocd.namespace }}
       kubectl apply -n {{ .Values.argocd.namespace }} -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

       kubectl apply -n argo-rollouts -f https://github.com/argoproj/argo-rollouts/releases/latest/download/install.yaml

     Rollouts se queda en curso para siempre. Faro lo comprueba al REGISTRAR el
